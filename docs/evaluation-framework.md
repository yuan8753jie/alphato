# AlphaTo 效果评判框架

## 评判维度

AlphaTo 的每个环节都需要独立的效果评判，以确保 AI 产出质量达标。

### 1. 热点抓取（/discover）

| 指标 | 说明 | 60分基线 | 80分标准 |
|------|------|---------|---------|
| **真实性** | 热点是否来自真实信息源 | 100%有来源标注 | 来源可点击验证 |
| **时效性** | 热点是否当前/近期 | 80%为当周热点 | 90%为当日/近3天 |
| **覆盖度** | 是否覆盖多个维度 | 至少5个分类有数据 | 所有9个分类都有 |
| **相关度** | 与品牌/行业的关联 | 50%直接相关 | 70%+直接相关 |
| **安全性** | 是否过滤了敏感内容 | 0条政治/负面 | 0条+竞品有警告标记 |

### 2. 选题生成（/topics）

| 指标 | 说明 | 60分基线 | 80分标准 |
|------|------|---------|---------|
| **创意度** | 是否有独特的切入角度 | 不是热点简单复述 | 角度新颖，团队说"不错" |
| **品牌契合** | 是否符合品牌调性 | 不违反红线规则 | 自然融入品牌/产品 |
| **类型配比** | 流量/信任/转化/人设比例 | 有3种以上类型 | 接近3:2:2:1 |
| **可执行性** | 描述是否足够具体 | 能理解内容方向 | 能直接开始写脚本 |
| **标题质量** | 是否像真实抖音标题 | 通顺有意义 | 有悬念/共鸣/记忆点 |

### 3. Persona 评审（AI Review）

| 指标 | 说明 | 60分基线 | 80分标准 |
|------|------|---------|---------|
| **差异化** | Persona 之间是否有明显区别 | 年龄/性别有差异 | 行为模式/偏好完全不同 |
| **评分分化** | 不同 Persona 的评分是否有差异 | 同一选题分差>2 | 分差>3，高低有明确理由 |
| **评语真实感** | 评语是否像真人说话 | 口语化 | 带个人特色/口头禅 |
| **推理可信度** | 每维度的理由是否合理 | 理由不矛盾 | 理由和Persona画像一致 |

### 4. 脚本生成（/topics/[id]）

| 指标 | 说明 | 60分基线 | 80分标准 |
|------|------|---------|---------|
| **结构完整** | hook+内容+CTA | 有开头中间结尾 | 3秒hook有力 |
| **平台感** | 是否有抖音短视频特色 | 时长30-60秒 | 节奏感强，有记忆点 |
| **分镜清晰** | 分镜表是否可操作 | 画面描述可理解 | 可直接交给摄影师 |
| **产品融入** | 产品植入是否自然 | 提到了产品 | 融入不违和 |

## 评判方式

### 自动评判（AI 自评）
每次生成后，用一个独立的 LLM 调用来评分。评分者不是生成者，避免"自己评自己"。

### 人工评判（创始人/团队打分）
关键节点拿真实案例打分，分数记录在案，指导 Prompt 迭代。

### A/B 对比
同一组热点，用不同 Prompt 生成选题，对比质量差异。

## 评判页面设计

/eval 页面：
1. 选择要评判的环节（热点/选题/Persona/脚本）
2. 自动拉取最近一次的产出
3. 逐条展示，每条下方有打分表单（1-10分 × 多个维度）
4. 提交后计算平均分，记录到 localStorage
5. 历史评分趋势图
